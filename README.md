# free-classroom

free-classroom 是一款基于 Flask 和 SQLite 的中文课表工具。导入教室课表后，可以按教学周、星期和节次查询空闲教室，也可以查看和编辑单间教室的课表。支持 Windows 本机运行和 Ubuntu 云服务器部署。

## 功能

| 页面 | 可用操作 |
| --- | --- |
| 查询 | 默认定位当前教学周和星期。可查询全天或自选连续节次，例如第 3–8 节。可筛选教室，并同时查找排有指定课程的教室。 |
| 教室课表 | 查看单间教室的日课表或周课表。点击周课表表头可打开当天。支持修改教室名称、逐节添加或编辑课程。 |
| 导入课表 | 下载 CSV 模板，多次追加文件，逐份移除。可指定替换周次，预览旧排课及校验结果。文件报错时可在网页中修改 CSV 并重新预览。 |
| 学期设置 | 设置第 1 周的周一、总周数和节次组。更换学期并确认后会清空现有教室和课表。 |

查询连续节次时，教室在所选范围内每一节都无排课才显示为「空闲」。勾选课程后，排有任一所选课程的教室也会列出，并标注课程与节次。

## Windows 本机启动

需要 Python 3.11 或以上版本。在项目根目录打开 PowerShell：

```powershell
python -m venv .venv
.\.venv\Scripts\python.exe -m pip install -r requirements.txt
.\start.cmd
```

打开 [本机网页](http://127.0.0.1:5000/)，使用期间保留启动窗口。安装依赖后也可双击 `start.cmd`。如果 5000 端口被占用，运行 `.\start.cmd --port 5001`，再访问 [备用地址](http://127.0.0.1:5001/)。

首次启动会创建 SQLite 数据库。到「学期设置」核对开学日期、周数和节次组，再导入课表。

## 导入 CSV

每间教室准备一份 UTF-8 编码的 CSV。可从网页下载模板。使用 Excel 时，保存为「CSV UTF-8（逗号分隔）」。

```csv
课程名,星期,节次,周次
电力电子技术,1,1-2,"1-5,7-12"
创新方法基础,1,9-10,"4,6-8"
```

| 字段 | 填写方式 |
| --- | --- |
| 课程名 | 课程的显示名称。 |
| 星期 | `1` 到 `7`，对应周一到周日。 |
| 节次 | 填单节或连续范围，例如 `3`、`1-2`。 |
| 周次 | 填单周、范围或组合。例如 `"4,6-8"` 表示第 4、6、7、8 周。字段内含英文逗号时，用英文双引号包起来。单双周先换算成具体周次。 |

1. 在「导入课表」添加文件，逐份确认教室编号和替换周次。
2. 点击「预览导入」。如果有错误，可点击「在线修改 CSV」，对照行号修正后重新预览。修改保存在待导入副本中。
3. 核对预览后点击「确认导入」。替换范围内的旧排课会按新 CSV 更新，CSV 留空的节次会清除旧排课。局部替换时，CSV 只填写本次要更新的周次。

照片课表可先整理到 CSV 模板，再核对课程、节次和周次。导入过的教室在整个学期内可查询，空白节次显示为「空闲」。

## 查看和维护课表

进入「教室课表」，选择教室和教学周。按日视图中可在节次组里添加或编辑课程，清空课程名并保存可将该节设为空闲。修改只应用到选定教室、教学周、星期和节次组。

切换到「按周」可查看周一到周日的排课。修改教室名称时，已有排课会跟随新名称，名称重复时页面会提示。

## 云服务器部署

将整个项目上传到 Ubuntu 服务器，在项目根目录用日常登录账号执行：

```sh
sh deploy/bootstrap-cloud.sh
```

脚本按需安装 Docker Engine 和 Compose，构建镜像并等待健康检查。默认使用 TCP 8000。通过公网访问时，在云安全组放行对应端口。网页可直接修改课表，个人使用可将入站来源限制为自己的公网 IP。域名访问、更新、课表同步和备份步骤见 [云服务器部署指南](deploy/README.md)。

## 数据与备份

默认数据库是 `data/classrooms.sqlite3`。备份时先停止应用，再复制 SQLite 文件。云端使用 Docker 挂载的数据目录，更新程序时继续使用原数据库。

本机和云端各有一份数据库。需要迁移时可使用部署指南中的同步脚本，它会先备份云端数据，再用本机快照替换。向 GitHub 提交时，应排除 `data/`、`.env`、虚拟环境和部署压缩包，项目的 `.gitignore` 已提供相应规则。

## 目录结构

| 路径 | 用途 |
| --- | --- |
| `app.py`、`timetable.py` | Flask 接口、CSV 校验、查询和数据存储 |
| `templates/`、`static/` | 页面模板、样式和交互 |
| `start.cmd`、`requirements.txt` | Windows 启动入口和 Python 依赖 |
| `deploy/` | Docker 配置、安装、更新、课表同步及部署说明 |
| `tests/` | 自动化测试 |
| `data/` | 运行时课表数据库 |

## 测试与排查

```powershell
.\.venv\Scripts\python.exe -m unittest discover -s tests -v
```

- 网页停在「正在加载」或新功能返回 404 时，先停止旧的本机服务，再从当前项目目录运行 `start.cmd` 并刷新页面。可打开 [本机状态接口](http://127.0.0.1:5000/api/state) 检查服务是否返回 JSON。
- 导入预览提示冲突时，核对同一教室、同一周、同一星期和同一节次是否填写了不同课程。
- 云端容器启动失败时，从项目根目录运行 `sudo docker compose -f deploy/compose.yaml --project-directory . logs --tail=60 app`。如果使用从零部署脚本创建的项目，在命令中加上 `-p classroom-bootstrap`。
